# 宝可梦平卡变 AR

给 Codex 使用的宝可梦 PTCG 扩图技能。输入卡牌原图、截图或单卡照片，也可以让 Codex 先搜索指定宝可梦的英文卡。

## 两种输出模式

| 模式 | 输出与构图 | 默认设置 |
| --- | --- | --- |
| 卡片模式 | 保留卡牌文字与数据，要求原插画的位置、尺寸和构图不变，仅延续外围画面 | 灰黑色圆角外框；也可选主题色框或无框 |
| 壁纸模式 | 去掉文字、卡片UI和外围框，宝可梦居中，可以重新构图 | 手机壁纸9:16；桌面壁纸16:9 |

卡片模式中，“无框”仅去掉外围框，仍保留卡牌文字与顶部金属名称栏轮廓。名称与HP后面透出插画，底部普通描述不加底色和框。

未上传原图时，优先从 [PkmnCards](https://pkmncards.com/) 查找英文卡，并保存原图来源、系列、编号和画师。要求多张不同卡时，优先选择不同插画。

## 安装

将本仓库下载到 Codex 的个人技能目录，文件结构应为：

```text
~/.codex/skills/pokemon-card-to-full-art/
├── SKILL.md
├── agents/openai.yaml
├── assets/
│   ├── ui-reference.png
│   └── border-reference.png
└── references/
    ├── prompt.md
    └── wallpaper-prompt.md
```

在 Codex 中调用 `$pokemon-card-to-full-art`，并提供图片或描述想找的卡片。生成依赖当前会话可用的图片编辑工具；仅下载技能本身不会提供图片生成服务。

## 使用示例

### 默认灰黑框卡片

```text
使用 $pokemon-card-to-full-art，把这张卡变成全景卡。
```

### 主题色框或无框

```text
使用 $pokemon-card-to-full-art，把这张妙蛙种子变成卡片模式，使用森林绿色的圆角外框。
```

```text
使用 $pokemon-card-to-full-art，把这张卡变成无外围框的全景卡，保留卡片文字和顶部金属名称栏。
```

### 无字居中壁纸

```text
使用 $pokemon-card-to-full-art，把这张卡变成9:16手机壁纸：不要文字、UI和卡框，宝可梦居中，保持原画风。
```

### 自动找图并批量生成

```text
使用 $pokemon-card-to-full-art，在PkmnCards找5张不同插画的英文妙蛙种子。
前3张分别做灰黑框、绿色主题框和无框卡片；后2张做无字居中壁纸。
```

## 当前限制

- 原画锁定是一项验收要求。只有参考图与自然语言指令的生成器，不能保证原画像素、位置或尺寸完全不变。
- 现有卡片测试仍出现重绘、角色缩放与位移，部分结果缺少顶部金属栏。这些结果应称为预览，不能宣称严格保真。
- 壁纸允许重新构图，按主体居中、画风与角色忠实、无文字无UI无框检查。
- 提示词和技能结构校验通过，不代表卡片数据、文字或图像质量已经通过检查。输出仍需与原卡核对。

## 文件说明

- [SKILL.md](SKILL.md)：模式选择、找图、生成与验收规则。
- [卡片提示词](references/prompt.md)：卡片模式与三种外围框选项。
- [壁纸提示词](references/wallpaper-prompt.md)：无字居中壁纸模式。
- `assets/`：UI与外围框参考。仅参考对应的版式特征，不复制参考卡的角色、EX标识或游戏数据。

参考图中的宝可梦角色与卡牌素材版权归各自权利人所有。本项目是非官方的生成工作流，与宝可梦官方无关联。
