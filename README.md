# 宝可梦平卡变 AR

给 ChatGPT 与 Codex 使用的宝可梦 PTCG 扩图技能。输入卡牌原图、截图、单卡照片或多卡合照，也可以从宝可梦亚洲官网搜索卡片并挑选候选，或指定查找英文卡。

## 两种输出模式

| 模式 | 输出与构图 | 默认设置 |
| --- | --- | --- |
| 卡片模式 | 保留卡牌文字与数据，要求原插画的位置、尺寸和构图不变，仅延续外围画面 | 灰黑色圆角外框；也可选主题色框或无框 |
| 壁纸模式 | 去掉文字、卡片UI和外围框，宝可梦居中，可以重新构图 | 手机壁纸9:16；桌面壁纸16:9 |

卡片模式中，“无框”仅去掉外围框，仍保留卡牌文字与顶部金属名称栏轮廓。名称与HP后面透出插画，底部普通描述不加底色和框。

未提供卡片时，优先从 [宝可梦亚洲官方网站](https://asia.pokemon-card.com/) 搜索，提供通常3–5张不同插画的候选，附原图预览（可展示时）、卡名、系列／编号、语言／地区、来源链接和画面特点，选定后再生成。也可以明确让技能自行选图并直接生成。没有指定宝可梦时，会先选不同角色、适合扩图的普通卡供挑选。

中文卡可从 [台湾站](https://asia.pokemon-card.com/tw/card-search/) 或 [香港站](https://asia.pokemon-card.com/hk/card-search/) 查找，并标明实际卡面语言；指定英文卡时可使用 [PkmnCards](https://pkmncards.com/)。生成时保存原图来源、系列、编号和画师；多张不同卡优先选择不同插画。

## 安装

### 在 ChatGPT 中安装

#### 桌面端本地安装

在支持本地电脑访问与 skill 安装的 ChatGPT 桌面端 Work 对话中，发送：

```text
请安装这个 skill：https://github.com/chuyu1018/pokemon-card-to-full-art
技能位于仓库根目录，请保留完整的 assets、references 和 agents 目录。
```

安装完成后，在下一轮对话输入 `@`，搜索并选择「宝可梦平卡变 AR」或 `pokemon-card-to-full-art`，然后上传原卡图片并描述需求。例如：

```text
把这张卡变成全景卡，使用默认灰黑色圆角外框。
```

本地安装仅作用于相应电脑环境，不代表已经安装到 ChatGPT 工作区，也不保证自动同步到网页或手机。桌面端独立技能与调用方式见 [OpenAI 官方 Build skills 文档](https://learn.chatgpt.com/docs/build-skills)。

#### 通过工作区 Skills 页面安装

适用于已开放 Skills 功能的 ChatGPT 工作区；当前官方列出的适用用户包括符合条件的 Business、Enterprise、Healthcare 和 Edu 用户，具体取决于工作区设置与产品可用性。

1. 从本仓库的 **Code → Download ZIP** 下载文件，解压后保留完整技能目录；上传时按当前界面要求准备技能包，不要只保留 `SKILL.md` 而遗漏参考文件。
2. 在 ChatGPT 侧栏打开 **Plugins（插件）→ Skills（技能）**。
3. 选择 **Create → Upload from your computer**，上传技能包，按提示完成扫描与安装。
4. 安装后输入 `@` 选择本技能，再上传卡牌图片或描述想找的卡片。

如果没有 Skills 或上传入口，请检查账户与工作区是否支持此功能。完整操作及可用范围见 [OpenAI 官方 Skills in ChatGPT 说明](https://help.openai.com/en/articles/20001066-skills-in-chatgpt)。

## 使用示例

以下示例使用 Codex 的 `$pokemon-card-to-full-art` 写法；在 ChatGPT 中先通过 `@` 选中本技能，再发送相同的需求描述即可。

### 默认灰黑框卡片

```text
使用 $pokemon-card-to-full-art，把这张卡变成全景卡。
```

### 主题色框或无框

```text
使用 $pokemon-card-to-full-art，把这张妙蛙种子变成卡片模式，使用森林绿色的圆角外框。
```

```text
使用 $pokemon-card-to-full-art，把这张卡变成无外围框的全景卡，保留卡片文字和顶部金属名称栏。
```

### 无字居中壁纸

```text
使用 $pokemon-card-to-full-art，把这张卡变成9:16手机壁纸：不要文字、UI和卡框，宝可梦居中，保持原画风。
```

### 没有卡片时，从官网搜索并选择

```text
使用 $pokemon-card-to-full-art，我没有卡图，请从宝可梦亚洲官网找几张妙蛙种子，给我带预览和来源的选项，选定后再生成。
```

```text
使用 $pokemon-card-to-full-art，从宝可梦亚洲官网自行选一张适合扩图的伊布，直接生成灰黑框全景卡。
```

### 指定英文卡并批量生成

```text
使用 $pokemon-card-to-full-art，在PkmnCards找5张不同插画的英文妙蛙种子。
前3张分别做灰黑框、绿色主题框和无框卡片；后2张做无字居中壁纸。
```

## 多卡照片与原图质量

- 上传一张包含多张卡的照片时，先按原位置编号，逐张核对边界、朝向和比例，可靠裁切、旋转及透视校正后复查，避免选错卡、倒置、镜像或拉伸。
- 列出各卡的位置与检查结果，询问生成其中哪张还是全部；已经明确选择时不重复问。选中的卡逐张独立生成，保留编号对应关系。
- 每张卡生成前都检查畸变和反光。严重透视、弯折或反光过曝导致无法可靠辨认、校正时，不允许使用该图生成，也不先试生成来碰运气。请补拍清晰正面图，或选择经核对的同版本清晰卡图。
- “全部生成”也须逐张通过检查；不合格的卡会说明原因，其他合格卡可以继续。此规则同时适用于卡片和壁纸模式。

## 生成次数与检查

- 默认每张生成一轮，不为轻微的位置、尺寸、居中、边框或构图调整反复生成。
- 检查出文字错误、脸部与原卡明显不同、严重错位、多余UI等明显问题时，最多追加两轮定向修正；问题解决即停止，仍有问题则标为预览并说明。轻微偏差或未达到严格保真标准本身不触发重生成；用户明确要求继续修改时按请求处理。
- 若图片工具安全检查拦截输出，会如实说明未获得可交付图片，并在工具允许的范围内提出修改方案；不采用打码再还原来绕过检查。

## 当前限制

- 原画锁定是一项验收要求。只有参考图与自然语言指令的生成器，不能保证原画像素、位置或尺寸完全不变。
- 现有卡片测试仍出现重绘、角色缩放与位移，部分结果缺少顶部金属栏。这些结果应称为预览，不能宣称严格保真。
- 壁纸允许重新构图，按主体居中、画风与角色忠实、无文字无UI无框检查。
- 提示词和技能结构校验通过，不代表卡片数据、文字或图像质量已经通过检查。输出仍需与原卡核对。
