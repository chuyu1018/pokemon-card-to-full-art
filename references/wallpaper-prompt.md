# 壁纸模式提示词

执行者补入真实原卡、目标比例、原画场景和宝可梦姿态。手机壁纸默认9:16，用户指定比例优先。**不追加卡片模式的原位置锁定、文字保留、顶部金属栏或外围框指令。**

将输入宝可梦卡中的插画扩展为完整无字壁纸。输入卡图只提供角色、原画风、姿态、表情、光照和场景，不保留卡面版式。

按指定画幅重新构图，使目标宝可梦身体的视觉中心位于画面中部，姿态自然完整、主体清晰。可以移动和等比缩放原角色、重新安排外围环境以适配居中壁纸；保持其身份、造型、表情、姿态、场景意图和原画笔触。不能只把一张完整卡片摆到画面中央，也不能凭空再加一只宝可梦。

根据原画环境向四周自然续画，保留相同材质、色彩、透视、光线和氛围。没有原画的地方延伸成连续场景，不能用镜像、重复拼贴或模糊边带填充。

彻底去除所有卡名、HP、招式文字、能量与属性符号、编号、画师文字、版权行、标志、卡框、金属名称条、图鉴横条、底部UI及其他排版。最终只有一幅完整插画，四边均为自然场景，无文字、无卡片边框、无悬浮卡牌、无桌面或样机。来源和画师信息另存在交付清单，不画进壁纸。

输出不透明的完整壁纸。生成后检查比例、主体居中、身份姿态及画风忠实、无文字无UI无边框、场景续接自然。壁纸允许重构图，不使用卡片模式的原位置验收标准。
